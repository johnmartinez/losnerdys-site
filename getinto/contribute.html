Got in? Pull the next one up.

Write the guide you wish someone had handed you. One Markdown file, 3 to 5 pillars, and your pillars become an animated explainer for the site, YouTube, and the Reels crowd.

// how it works

Same template, every field

  1. Pick a field you actually work in. DevOps, DevSecOps, Platform Eng, data, cloud, whatever you do for a living.
  2. Pick 3 to 5 pillars, in the order someone should learn them. Shared foundations first, then the one last pillar that makes it your field. Cyber's is Security: "now learn how each layer breaks."
  3. One free resource per pillar. Something a student can start tonight without a credit card. Tools and a hands-on exercise are optional extras.
  4. Write the rest: a short intro, why this order, where to find your people, and how you got in. Short and honest beats long and polished.
  5. Send it. We edit for voice, render your video, and it goes live with your name on it.
// voice

Write it like you'd say it

  • Casual and precise. Talk like you're explaining it at the taquería, but get the tech right.
  • Code-switching welcome. Spanglish is how a lot of us think. Use it.
  • No gatekeeping. No 47-cert roadmaps, no "just get a CS degree." What actually worked.
  • Free first. Every pillar needs at least one free way in.
  • Keep the animation lines short. Pillar names up to about 12 characters, the one-liner up to about 48. They animate.
// the template

Copy this

Save it as _getinto/your-field.md. Everything above the second --- drives the card, the page, and the animation. Everything below it is your write-up, in plain Markdown.

Two ways in

Open a PR

Fork losnerdys-site, add _getinto/your-field.md and a square headshot in assets/getinto/authors/, and open a pull request. We'll render the video and merge.

Start the file on GitHub

Not a Git person?

All good. Fill in the template in any text editor and send it to John with your headshot. Markdown, a Google Doc, whatever. We'll do the rest.
